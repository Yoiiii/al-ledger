小账房 · UI 静态原型

依据《记账Agent-需求文档.md》§4 UI 设计生成 · 暗色玻璃拟态风格 · Tailwind CSS + Lucide 图标 · 移动端优先（480px 容器）

记账（首页 · 聊天）

消息流 + 气泡；记账确认卡片 / 查账列表卡片 / 统计卡片 / 骨架态 / 失败重试；快捷 chips、麦克风（脉冲动画）、发送

账单列表

日期倒序分组 + 当日小计；分类/时间筛选；点击行弹出底部编辑抽屉（分类宫格、支付方式、删除）

统计

本周/本月/自定义切换；总支出/总收入/笔数三卡；分类环形图、每日趋势柱状图、分类排行
页面间通过底部 Tab 互相跳转；账单页默认展示"编辑抽屉"的弹出效果，便于评审。需联网加载 Tailwind CDN 与 Lucide 图标。
